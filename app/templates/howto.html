1 Vue d'ensemble

ReviewV2 est un outil de validation et d'édition des photos d'œuvres. Il permet de :

📁

Voir les photos sur disque

Parcourir les répertoires FM, A5, NP, 300, TIFF pour chaque œuvre.

🗃

Gérer les champs Odoo

Assigner les photos aux champs Odoo (Super HD, Back, Detail…) en quelques clics.

✏

Éditer les photos

Recadrer, redresser, ajuster luminosité / contraste / saturation, générer FM+A5.

📤

Uploader de nouvelles photos

Ajouter une photo directement depuis ton disque, nommée et assignée automatiquement.

2 Mode Express — validation rapide

Le Mode Express est conçu pour traiter 15 000+ œuvres rapidement. Accès via le bouton ⚡ Mode Express en haut de l'accueil.

Navigation

La liste défile librement à la souris. Les détails (vignettes disque + champs Odoo) se chargent automatiquement au fil du scroll — pas besoin de cliquer.

Filtres

En haut de page, deux rangées de filtres :

  • Statut — In Stock In Transit Returned Delivered — filtres cumulables (OU)
  • Rôle disque — BACK, IN SITU, DETAIL, FRAME, SIGNATURE, MAIN — cliquer une fois = ✓ présent, deux fois = ✗ absent, trois fois = neutre
  • Pas sur disque — affiche uniquement les œuvres sans aucun fichier sur disque

Assigner une photo existante (disque → Odoo)

1
Clique sur une vignette disque (côté gauche) → elle s'entoure en orange, une barre apparaît en haut
2
Clique sur le champ Odoo cible (côté droit) → assigné instantanément
3
Esc pour annuler la sélection

Uploader une nouvelle photo vers un champ Odoo

1
Clique directement sur un champ Odoo sans avoir sélectionné de photo, ou clique le bouton 📤 sur le slot
2
Un modal s'ouvre — glisse ou sélectionne le fichier depuis ton disque
3
Clique ⬆ Envoyer & Assigner → le fichier est renommé automatiquement (ARTIST-ID_BACK.jpg etc.), sauvegardé dans FM/, et le champ Odoo est mis à jour

Auto-assign

Le bouton ⚡ Auto-assign dans le détail d'une œuvre assigne automatiquement toutes les photos disque aux bons champs selon les conventions de nommage. Raccourci clavier : A.

3 Fiche œuvre

Accès en cliquant une œuvre depuis l'accueil, ou via 🔗 Fiche dans le Mode Express.

  • Panneau gauche — toutes les photos sur disque, par répertoire (FM / A5 / NP / 300 / TIFF). Clique une photo pour la sélectionner (bordure jaune).
  • Panneau droit — les 12 champs Odoo avec leur photo actuelle. Clique un slot après avoir sélectionné une photo pour assigner.
  • Bouton 📤 Upload — sur chaque slot, permet d'uploader un nouveau fichier directement sans passer par l'étape de sélection à gauche.
  • ⚡ Auto-assign — assigne automatiquement selon les rôles détectés dans les noms de fichiers.
  • ✏ Éditer — icône sur chaque photo en survol, ouvre l'éditeur.
  • ← / → — navigation entre les œuvres.

4 Éditeur de photos

Accès via l'icône ✏ sur n'importe quelle photo. L'éditeur propose plusieurs outils dans le panneau de droite :

📤 Nouvelle version

Glisse ou sélectionne un fichier pour remplacer la photo actuelle. L'ancienne version est automatiquement sauvegardée dans _backups/ avant d'être écrasée.

↻ Rotation

Boutons -90° / +90° / 180° pour les rotations simples.

📐 Redresser

Pour corriger une photo légèrement de travers :

1
Clique ✏ Tracer — un overlay sombre apparaît sur la photo
2
Clique et glisse le long d'un bord qui devrait être horizontal ou vertical — une ligne jaune apparaît avec l'angle calculé en temps réel
3
Clique Appliquer — la correction est mémorisée
4
Sauvegarde normalement — Pillow applique la rotation fine et recadre automatiquement les bords blancs

✂ Recadrage

1
Choisis un ratio (Libre / 1:1 / 4:3 / 3:2 / 16:9) puis clique Activer
2
Glisse les poignées ou dessine un nouveau cadre dans la zone sombre
3
Clique Appliquer pour valider le recadrage

🎨 Ajustements

Sliders de luminosité, contraste, saturation — aperçu en temps réel via CSS filter. Appliqués au pixel lors de la sauvegarde.

📐 Générer versions

BoutonDescription
→ FMGénère une version max 3307px dans FM/
→ A5Génère une version max 1980px dans A5/
→ FM+A5Génère les deux en une fois
💾 RemplacerÉcrase le fichier original avec toutes les modifications

Astuce : la sauvegarde applique toujours toutes les modifications en cours (rotation + redressement + recadrage + ajustements couleur) en une seule passe.

5 Ajouter des photos

Via le Mode Express (bouton 📤 Ajouter photos)

Dans le header du Mode Express, le bouton 📤 Ajouter photos permet d'uploader un ou plusieurs fichiers dans un répertoire choisi (FM / A5 / NP / 300 / TIFF). Les fichiers existants ne sont pas écrasés.

Via un slot Odoo (upload + assignation en une étape)

Depuis la fiche œuvre ou le Mode Express, clique le bouton 📤 sur n'importe quel champ Odoo. Le fichier uploadé est :

  • Renommé automatiquement selon le champ cible (ARTIST-ID_BACK.jpg, _MAIN.jpg, etc.)
  • Converti en JPEG et sauvegardé dans FM/
  • Assigné directement au champ Odoo
Champ OdooSuffixe généré
Super HD / Main HD / Web / HD Web_MAIN.jpg
A6_MAIN_A5.jpg
Back_BACK.jpg
Detail 1 / Detail 2_DETAIL_1.jpg / _DETAIL_2.jpg

Si un fichier du même nom existe déjà dans FM/, un compteur est ajouté automatiquement : _BACK_2.jpg, _BACK_3.jpg, etc.

6 Assigner aux champs Odoo

Il existe deux façons d'assigner une photo à un champ Odoo :

  • Photo existante sur disque → sélectionne la photo à gauche → clique le slot cible à droite
  • Nouvelle photo depuis ton disque → clique directement le slot ou son bouton 📤 → modal d'upload

L'assignation envoie l'URL publique de la photo (https://review.operagallery.com/photo/FM/...) directement dans le champ Odoo via l'API JSON-RPC.

Chaque assignation est enregistrée dans le journal d'activité avec l'utilisateur, la date, le champ et le fichier.

7 Filtres du Mode Express

FiltreLogiqueUsage
Statut (In Stock, In Transit…)OU — plusieurs statuts cumulablesSe concentrer sur les œuvres les plus urgentes (In Stock en priorité)
Rôle disque (BACK, MAIN…)ET — tous les rôles sélectionnés doivent correspondre1 clic = présent (vert ✓), 2 clics = absent (rouge ✗), 3 clics = neutre
Pas sur disque—Identifier les œuvres sans aucun fichier photo
Recherche texte—Filtrer par ID, titre ou artiste

Exemple : In Stock + ✗ BACK → toutes les œuvres en stock qui n'ont pas de photo de dos.

9 Comptes utilisateurs

L'authentification utilise un login + mot de passe + code TOTP (Google Authenticator ou Authy).

Pour configurer l'authentificateur, ouvrir le lien :

https://review.operagallery.com/setup-otp/[login]

Exemple pour charles : https://review.operagallery.com/setup-otp/charles

Scanner le QR code avec Google Authenticator → le compte est prêt. Pas besoin d'être connecté pour accéder à cette page.
